# Resaca Model Map: public website

This is the **public display-only** companion to a separate private research-history archive.

### View the live map

[**Open the interactive map**](https://bridgettc.github.io/Resaca-Model-Map/)

Compare 44 polygon layers across resaca model-development stages, view the final 914 polygons, overlay a colorized detrended DEM, switch to satellite imagery, and click individual polygon features to inspect metadata.

**Scientific cautions:** Polygon geometries here are simplified for visualization, not precise boundary validation. Layer counts overlap historically; do not add them. The colorized raster is a resampled DEM visualization with clipped and normalized colors, not the full 5-meter elevation model or a downloadable georeferenced DEM.

The original raster and code history remain in the separate private research archive. This public repository intentionally publishes only map-ready data and static website assets.
